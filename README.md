Student Database

Project Description

A MySQL-based Student Management Database designed to manage student details, courses, admissions and fee payments.

Technologies Used

- MySQL
- SQL
- Git
- GitHub

Database Tables

1. Students
2. Courses
3. Admissions
4. Payments

SQL Operations

- INSERT
- UPDATE
- DELETE
- INNER JOIN
- LEFT JOIN
- GROUP BY
- SUM and COUNT
- Payment history
- Pending fee calculation
- Transactions (COMMIT and ROLLBACK)

Objective

To understand relational database management, primary keys, foreign keys, SQL queries and database transactions.
